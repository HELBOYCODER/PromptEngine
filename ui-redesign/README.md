# PromptEngine — بازطراحی رابط اندروید

جایگزین پوشه‌های `templates/` و `static/` داخل `app.imy` (سورس پایتون اپ).
بک‌اند (مسیرهای `/models` ، `/translate` ، `/settings` ، `/usage`) و شناسه‌های DOM بدون تغییر مانده‌اند.

## چه چیزی عوض شد
- طراحی mobile-first با بالای‌صفحه‌ی ساده، کارت ورودی، دکمه‌ی ثابت «تبدیل کن» پایین صفحه (ناحیه‌ی شست)
- نتیجه با تب انگلیسی / فارسی، آکاردئون برای الزامات، فرض‌ها، اطلاعات ازدست‌رفته و پیشنهادها (با شمارنده)
- مصرف توکن و تنظیمات به‌صورت bottom sheet؛ دکمه‌ی Back اندروید همچنان درست کار می‌کند
- حالت خالی، لودینگ روی دکمه، بازخورد «کپی شد»، رعایت safe-area و `prefers-reduced-motion`
- کپی مستقیم از پل `PromptEngineNative.copy`

## باگ قدیمی که رفع شد
`mobile.js` قبلی در انتهای فایل متن چت (کد پایتون و HTML) چسبیده داشت. این خطای سینتکس باعث می‌شد کل فایل اجرا نشود، یعنی پل کپی نیتیو و `peHandleBack` عملاً کار نمی‌کردند.

## نصب
فایل‌ها را روی سورس اپ کپی کنید و APK را دوباره بسازید:

    templates/index.html -> templates/index.html
    static/*             -> static/*

پیش‌نمایش‌ها در `preview/` هستند.
