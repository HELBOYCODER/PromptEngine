# PromptEngine — Android

اپلیکیشن اندروید PromptEngine (نسخه **1.0.1**)

## 📦 دانلود و نصب

فایل APK کامل حدود **40MB** است و به همین دلیل به **۳ پارت** تقسیم شده. برای نصب:

1. هر سه فایل زیر را دانلود کنید و در **یک پوشه** قرار دهید:
   - `PE101_00.part` (~19MB)
   - `PE101_01.part` (~19MB)
   - `PE101_02.part` (~1.9MB)

2. فایل `rejoin_apk.sh` را هم دانلود کنید و اجرا کنید:
   ```bash
   bash rejoin_apk.sh
   ```
   یا به‌صورت دستی:
   ```bash
   cat PE101_00.part PE101_01.part PE101_02.part > PromptEngine-1.0.1.apk
   ```

3. فایل ساخته‌شده `PromptEngine-1.0.1.apk` را روی گوشی نصب کنید (نصب از منابع ناشناس را فعال کنید).
